# Напоминалка для Windows 11

Приложение на Python + tkinter с хранилищем SQLite3. Напоминания срабатывают
даже когда главное окно свёрнуто: проверка идёт в основном потоке через
`root.after()`, а уведомление показывается отдельным окном поверх всех окон
или системным toast Windows.

## Запуск

```powershell
python main.py
```

Никаких обязательных сторонних библиотек нет — достаточно стандартной
библиотеки Python 3.10+.

Необязательно для системных уведомлений Windows:

```powershell
pip install win10toast
python main.py
```

Затем включите галочку «Системное уведомление (win10toast)» в toolbar.
Если пакет не установлен или toast не сработал, автоматически показывается
всплывающее окно поверх всех окон.

## Структура

| Файл | Назначение |
|------|------------|
| `config.py` | Константы, статусы, форматы дат, путь к БД |
| `database.py` | Создание таблиц SQLite3 и все операции с напоминаниями |
| `notifier.py` | Popup поверх всех окон + необязательный системный toast |
| `gui.py` | Главное окно, форма добавления, фильтрация и логика проверки времени |
| `main.py` | Точка входа |
| `reminders.db` | Создаётся автоматически при первом запуске |

## Возможности

- Добавление, удаление напоминания. Форма добавления встроена в шапку окна:
  заголовок, описание, дата и время, а также кнопки быстрого выбора
  «Через 1 мин», «Через 5 мин», «Через 15 мин», «Через 1 час».
- Отметка «Готово» / «Отменено» из списка или прямо из popup.
- Фильтр по статусу: Все / Ожидает / Готово / Просрочено / Отменено.
- Автоматический перевод в «Просрочено» через 60 секунд после срабатывания
  (настраивается константой `OVERDUE_GRACE_SECONDS` в `config.py`).
- Проверка раз в секунду (`POLL_INTERVAL_MS` в `config.py`).
- В списке цветом выделяется фон всей строки, текст остаётся чёрным.
- При старте таблицы и индексы создаются, если их нет (`CREATE TABLE IF NOT EXISTS`).

## Формат даты в форме добавления

`ГГГГ-ММ-ДД ЧЧ:ММ`, например `2026-11-22 09:30`.
Также принимаются `ГГГГ-ММ-ДД ЧЧ:ММ:СС` и `ДД.ММ.ГГГГ ЧЧ:ММ`.
